# Fundamentos de Antigravity y Vibe Coding

## 1. Qué es Vibe Coding
Vibe Coding es una metodología emergente en la que el desarrollador interactúa con modelos y asistentes de Inteligencia Artificial mediante lenguaje natural, descripciones lógicas y contexto exhaustivo, delegando la redacción detallada y repetitiva del código a la máquina. Se fundamenta en "vibrar" (comunicar claramente la intención, el diseño y las reglas del sistema) para orquestar la resolución de problemas arquitectónicos y de lógica de negocio o de software de alto nivel.

## 2. Diferencia entre entorno web y entorno local
- **Entorno Web:** Es el espacio basado en el navegador (como repositorios online, IDEs en la nube, herramientas web). Por lo general es más accesible, no consume recursos drásticos del equipo del usuario, carece de requisitos de instalación, pero puede tener limitaciones de personalización, de conectividad y privacidad.
- **Entorno Local:** Es la computadora física (o máquina virtual local) del desarrollador. Requiere configurar y gestionar dependencias manualmente (Node.js, Git, variables de entorno). Brinda autonomía completa, permisos avanzados sobre herramientas como CLI y la libertad para desarrollar y probar offline u orquestar bases de datos propias sin latencia.

## 3. Qué es el modo Planning en Antigravity
El **modo Planning** (Planificación) es una fase analítica donde la herramienta de IA asume un rol estratégico. En vez de escribir código y modificar archivos casi a ciegas, el sistema investiga, reflexiona y traza un esquema paso a paso para afrontar una tarea compleja. Es ideal para definir la estructura de un documento, identificar dependencias o entender patrones de diseño antes de empezar a programar.

## 4. Qué es el modo Fast en Antigravity
El **modo Fast** (Rápido) está diseñado para la ejecución ágil, inmediata y directa. Elimina pausas contemplativas innecesarias o flujos explicativos para enfocarse puramente en generar, refactorizar o arreglar el código en cuestión de manera rápida. Es excelente para tareas repetitivas o bien aisladas.

## 5. Qué modelo de IA usarías para generar una aplicación completa y por qué
Para construir una aplicación completa utilizaría **Claude 3.5 Sonnet** (o bien **Gemini 1.5 Pro** si necesito procesar miles de archivos o grandes documentos de forma conjunta). Por el lado técnico:
- **Claude 3.5 Sonnet** sigue siendo puntero para programación y agilidad, sigue al pie de la letra las estructuras establecidas por el desarrollador y comete pocos errores de sintaxis en el ensamblaje de módulos.
- La combinación ideal asegura un **razonamiento complejo, comprensión del contexto y capacidad de refactorización constante**, claves para manejar una aplicación de inicio a fin.
